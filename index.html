01 A ideia central

O que é uma função?

Antes de qualquer fórmula, função é uma ideia simples: uma quantidade que depende de outra.

Pense no seu dia: o valor da corrida de aplicativo depende dos quilômetros rodados; a altura de uma bola lançada para cima depende do tempo; a área de um piso quadrado depende do tamanho do lado. Sempre que uma grandeza é determinada por outra, a Matemática chama isso de função.

📖 Definição (guarde esta!)
Uma função é uma regra que associa a cada valor de entrada x um único valor de saída y.

Escrevemos y = f(x) e lemos “f de x”. O x é a variável independente (a entrada, quem você escolhe); o y é a variável dependente (a saída, quem responde). O conjunto de entradas possíveis é o domínio; o de saídas, a imagem.

Uma mesma função pode vestir três roupas diferentes — e entender isso é metade do aprendizado:

📋 Tabela de valores 🧮 Lei algébrica (a fórmula) 📈 Gráfico no plano

A regra aqui é f(x) = 2x + 1: cada entrada é dobrada e somada de 1. Cada x entrega exatamente uma saída.

É função ou não é?

A regra de ouro: cada entrada pode ter UMA ÚNICA saída. Se um mesmo x apontar para dois valores de y, não é função. No gráfico, isso vira o famoso teste da reta vertical: se alguma reta vertical cortar o desenho em dois pontos, aquilo não é função.

🧠 Exemplo para nunca esquecer
“Idade → altura” é função? Em um instante sim: em cada data, você tem uma única altura. Já “altura → idade” não é: aos 1,60 m você pode ter ficado aos 14 e aos 15 anos. Uma entrada, duas saídas → não é função.

Resumindo: função é previsível — mesma entrada, sempre a mesma saída. ✅

02 Reta na certa

Função do 1º grau: f(x) = ax + b

Toda vez que algo cresce (ou diminui) sempre na mesma proporção, existe uma reta escondida ali.

Uma função do 1º grau (ou afim) tem a forma f(x) = ax + b, com a ≠ 0. O expoente do x é 1 — o maior que aparece. Casos particulares: se b = 0, chamamos de função linear (f(x) = ax, reta passando pela origem); se a = 0, vira função constante (uma reta horizontal — e deixa de ser de 1º grau!).

a Coeficiente angular

É a inclinação: a taxa de variação. Cada vez que x aumenta 1 unidade, y muda a unidades. Entre dois pontos: a = Δy/Δx. Se a > 0 a função cresce; se a < 0, decresce. Quanto maior |a|, mais “em pé” a reta.

b Coeficiente linear

É o valor inicial: o ponto onde a reta corta o eixo vertical, sempre em (0, b). Mudar b desliza a reta para cima ou para baixo sem girá-la — a inclinação continua a mesma.

🎯 Raiz (zero da função)

Onde a reta cruza o eixo x, ou seja, onde f(x) = 0: ax + b = 0 ⟹ x₀ = −b/a. Toda função de 1º grau tem exatamente uma raiz.

🌎 Exemplo real: graus Celsius → Fahrenheit

F(C) = 1,8·C + 32. Aqui a = 1,8: cada grau Celsius a mais vira 1,8 °F a mais (taxa constante → reta). E b = 32: por isso 0 °C = 32 °F. Raiz: C = −32/1,8 ≈ −17,8 °C, a temperatura em que Fahrenheit marca zero.

🚫 Erros comuns — não caia nessas!
  • f(x) não é “f vezes x”. É o nome da saída da máquina.
  • Quem diz se a reta sobe ou desce é o a, não o b.
  • a = 0 não é função de 1º grau: é uma constante (reta horizontal).

Estudo do sinal

A raiz divide a reta em duas metades. Para f(x) = 2x − 4 (raiz x = 2): à direita da raiz, f(x) > 0; à esquerda, f(x) < 0 — e se a < 0, tudo se inverte. No laboratório acima, arraste b e veja a raiz deslizando pelo eixo.

03 Curvas, vértices e máximos

Função do 2º grau: f(x) = ax² + bx + c

Quando a variação acelera — ou quando existe um ponto ótimo — a reta não basta. Entra a parábola.

Uma função do 2º grau (ou quadrática) tem a forma f(x) = ax² + bx + c, com a ≠ 0. Por que o x² aparece tanto na natureza? Porque ele surge sempre que uma grandeza multiplica a si mesma ou a outra que também varia: área (lado × lado), gravidade (o espaço depende de t × t), receita (preço × quantidade, quando um depende do outro).

Se b ou c forem zero, a função é incompleta, mas continua de 2º grau: x² − 4, 3x², −x² + 5x.

a Concavidade e abertura

a > 0 → concavidade para cima 🙂 (a parábola “segura água” e tem um mínimo). a < 0 → para baixo ☹ (tem um máximo). Quanto maior |a|, mais “fechada” ela é.

b e c Posição

c é o corte no eixo y: o ponto (0, c). O b “empurra” a parábola lateralmente: curiosidade elegante — no ponto x = 0, a curva está subindo/descendo com inclinação exatamente igual a b.

🎯 Raízes: quantas?

Onde a parábola cruza o eixo x (f(x)=0). Podem ser duas, uma (ela apenas toca) ou nenhuma (não chega ao eixo). Quem decide é o discriminante Δ.

Δ (delta) e a fórmula de Bhaskara

O discriminante Δ = b² − 4ac conta quantas raízes existem — e a fórmula x = (−b ± √Δ) / 2a diz onde elas estão:

Δ > 0 → duas raízes reais distintas Δ = 0 → uma raiz real (dupla): a parábola beija o eixo x Δ < 0 → nenhuma raiz real: √Δ não existe nos reais
✏️ Exemplo resolvido, sem pressa: f(x) = x² − 4x + 3

① Coeficientes: a = 1, b = −4, c = 3 → concavidade para cima.
② Δ = (−4)² − 4·1·3 = 16 − 12 = 4 → duas raízes.
③ x = (4 ± √4)/2 = (4 ± 2)/2 → x₁ = 1 e x₂ = 3.
④ Vértice: xv = −b/2a = 4/2 = 2; f(2) = −1 → ponto de mínimo V(2, −1).
⑤ Repare: o vértice fica exatamente no meio das raízes (1 e 3). Sempre fica!

O vértice: o ponto mais importante da parábola

xv = −b/2a e yv = −Δ/4a. Se a < 0, o vértice é o valor máximo da função (o topo do voo da bola, o lucro máximo da loja); se a > 0, é o mínimo. A reta vertical x = xv é o eixo de simetria: a parábola é um espelho em torno dela. Outra forma útil de escrever: f(x) = a(x − x₁)(x − x₂) quando existem raízes.

“O vértice não é o fim da curva: é o ponto onde tudo muda de sentido.” — Prof. Anderson Daniel

🚫 Erros comuns do 2º grau
  • Se a = 0, a função não é de 2º grau (teste o botão “a = 0” no laboratório!).
  • Δ < 0 não significa “raiz zero” — significa que a parábola nunca toca o eixo x.
  • O vértice não é a “média de qualquer coisa”: xv = −b/2a, sempre. E o valor máximo/mínimo é yv = f(xv), não xv!

Onde elas se encontram?

A interseção de dois gráficos resolve a pergunta “quando as saídas são iguais?” — basta igualar as leis:

x + 1 = x² − 1 ⟺ x² − x − 2 = 0
⟹ x = 2 ou x = −1

Substituindo de volta: pontos (2, 3) e (−1, 0). Uma reta e uma parábola se encontram em no máximo 2 pontos — coerente com o “2” do 2º grau.

🐢🐇 Quem vence no longo prazo?

Compare x² e 100x: a reta parece imbatível… até x = 100. Depois disso, a parábola dispara e nunca mais é alcançada. Crescimento quadrático sempre alcança o linear. É por isso que juros compostos e epidemias “explodem”.

06 Prática deliberada

Exercícios com solução passo a passo

Tente primeiro no caderno. Só depois abra a solução — e compare o raciocínio, não apenas o resultado. (Dica: ao imprimir, as soluções abrem sozinhas.)

1 Para f(x) = 3x − 7, calcule f(0), f(2) e f(−1).
Substitua x em cada caso: f(0) = 3·0 − 7 = −7; f(2) = 3·2 − 7 = 6 − 7 = −1; f(−1) = 3·(−1) − 7 = −3 − 7 = −10. Calcular f(a) é sempre a mesma operação: trocar x pelo número.
2 Encontre a raiz de f(x) = −4x + 16.
Raiz ⟺ f(x) = 0: −4x + 16 = 0 ⟹ 4x = 16 ⟹ x = 4. Conferindo: f(4) = −16 + 16 = 0 ✓. O gráfico corta o eixo x em (4, 0) e o eixo y em (0, 16).
3 Uma função afim satisfaz f(1) = 5 e f(3) = 9. Determine sua lei.
Inclinação: a = Δy/Δx = (9 − 5)/(3 − 1) = 4/2 = 2. Depois use um ponto: f(1) = 5 ⟹ 2·1 + b = 5 ⟹ b = 3. Lei: f(x) = 2x + 3. Conferindo: f(3) = 6 + 3 = 9 ✓. Dois pontos sempre determinam uma reta!
4 Analise f(x) = 2x − 4: crescimento, raiz, corte no eixo y e sinal.
a = 2 > 0 ⟹ crescente. Raiz: 2x = 4 ⟹ x = 2. Corte em y: (0, −4). Sinal: f(x) > 0 para x > 2 e f(x) < 0 para x < 2 (a raiz é a fronteira).
5 Resolva x² − 5x + 6 = 0 via Bhaskara.
a = 1, b = −5, c = 6. Δ = 25 − 24 = 1 (duas raízes). x = (5 ± 1)/2 ⟹ x₁ = 2, x₂ = 3. Verificação elegante: soma das raízes = 5 = −b/a; produto = 6 = c/a ✓
6 E x² + 4x + 4 = 0? O que há de especial?
Δ = 16 − 16 = 0 ⟹ raiz dupla: x = −4/2 = −2. O lado esquerdo é um quadrado perfeito: (x + 2)². No gráfico, a parábola apenas toca o eixo x no ponto (−2, 0) — o vértice está sobre o eixo.
7 Mostre que −x² + 6x − 10 não tem raízes reais e diga o sinal da função.
Δ = 36 − 4·(−1)·(−10) = 36 − 40 = −4 < 0 ⟹ nenhuma raiz real: a parábola nunca cruza o eixo x. Como a = −1 < 0 (concavidade para baixo), ela fica inteira abaixo do eixo: f(x) < 0 para todo x. (Confirme no Laboratório 2!)
8 O lucro de uma loja é L(x) = −x² + 40x − 300 (x = quantidade vendida). Encontre o lucro máximo e a faixa com lucro positivo.
xv = −40/(2·(−1)) = 20 unidades. L(20) = −400 + 800 − 300 = R$ 100 (lucro máximo). Raízes: Δ = 1600 − 1200 = 400 ⟹ x = (40 ± 20)/2 ⟹ 10 e 30. Como a < 0, L > 0 entre as raízes: é preciso vender entre 10 e 30 unidades para ter lucro.
9 Uma bola segue h(t) = −5t² + 30t. Altura máxima? Quando volta ao chão?
Ápice: tv = −30/(2·(−5)) = 3 s; h(3) = −45 + 90 = 45 m. Volta ao chão quando h = 0: −5t(t − 6) = 0 ⟹ t = 0 (lançamento) ou t = 6 s. Simetria da parábola: sobe 3 s, desce 3 s.
